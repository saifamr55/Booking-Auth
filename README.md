## 📖 نظرة عامة

الـ Frontend مصمم ليكون مرناً ومرتبطاً بسيرفر الـ Backend عبر `axios` موحد مع **Interceptors** متقدمة لإدارة التوكنات وتجديدها تلقائياً عند انتهاء صلاحيتها. يدعم تدفق عمل (Workflow) كامل لعمليات الـ Authentication:
1. **التسجيل الجديد (Sign Up):** إدخال البيانات والتحقق من صحتها، ثم إرسال وتأكيد كود الـ OTP.
2. **تسجيل الدخول (Login):** حفظ تلقائي للـ `accessToken` و `refreshToken` في الـ `localStorage`.
3. **استعادة كلمة المرور (Forgot/Reset Password):** طلب كود الاستعارة عبر الايميل وإعادة تعيين باسورد جديد بـ Modals منفصلة ونظيفة.

## ✨ الميزات الرئيسية

- **🔐 مصادقة متكاملة وآمنة:** تسجيل دخول، تسجيل بـ OTP، واستعادة كلمة المرور عبر نوافذ تفاعلية (Modals).
- **🔄 إدارة تلقائية للـ Tokens:** استخدام `axios` Interceptors لتضمين الـ Bearer Token تلقائياً ومعالجة أخطاء الـ Unauthorized.
- **🛡️ التحقق من المدخلات (Validation):** نظام Validation مركزي ومنفصل للتحقق من صحة الإيميل، قوة كلمة المرور، وتطابق الحقول وأرقام الهواتف (مصر: 11 رقم).
- **🎨 تصميم متجاوب ومنظم:** مكونات React مقسمة باحترافية (`AuthForm`, `OtpModal`, `ResetPasswordModal`) مع استايلات CSS نظيفة ومخصصة.
- **⚡ أداء عالي:** مبني باستخدام **Vite** لتجربة تطوير وسرعة بناء فائقة.

## ✅ المتطلبات الأساسية

قبل البدء، تأكد من تثبيت الآتي على جهازك:
- **Node.js** (يفضل الإصدار 18 أو أحدث)
- **npm** (يأتي تلقائياً مع Node.js)

تأكد من تشغيل الـ Backend الخاص بك محلياً على المنفذ الافتراضي (`http://localhost:5000/api`) أو حسب إعدادات الـ Backend.

## 🚀 خطوات التشغيل

### 1. استنساخ المشروع وتثبيت الحزم
```bash
git clone https://github.com/saifamr55/Booking-Auth
cd Booking-Auth/src
npm install
 
###2. إعداد متغيرات البيئة (.env)
أنشئ ملف .env في جذر المشروع (أو عدل الملف الموجود بناءً على القالب):
```bash
VITE_API_BASE_URL=http://localhost:5000/api

###3. تشغيل السيرفر المحلي للتطوير
```bash
npm run dev

سيفتح التطبيق افتراضياً على: http://localhost:5173 (أو المنفذ المحدد في الـ terminal).
