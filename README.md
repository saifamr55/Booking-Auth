# BookAThing - Client Portal 🚀

تطبيق ويب متكامل لإدارة الحجوزات، مُبني باستخدام مكتبة React.js كجزء من مشروع MERN Stack، ويشمل وحدة مصادقة وإدارة حسابات شاملة ودعم للغتين العربية والإنجليزية.

---

## 🌟 المميزات (Features)

* **نظام مصادقة متكامل (Authentication Flow):**
  * تسجيل الدخول وإنشاء حساب جديد.
  * استعادة كلمة السر عبر كود التفعيل (OTP).
  * خيار تسجيل الدخول عبر حساب جوجل (Google Sign-In).
* **تحقق دقيق من البيانات (Inline Validation):**
  * إظهار رسائل الأخطاء تفاعلياً أسفل كل حقل بدون استخدام Alerts.
  * تقييد رقم الهاتف ليتكون من 11 رقماً بالضبط.
  * اشتراط كلمة سر معقدة (8 خانات على الأقل، حروف، أرقام، ورموز خاصة).
* **دعم متعدد اللغات (Internationalization - i18n):**
  * تحويل سلس بين اللغتين العربية والإنجليزية.
  * دعم اتجاه الكتابة من اليمين لليسار (RTL) للغة العربية ومن اليسار لليمين (LTR) للإنجليزية تلقائياً.
* **تصميم مرن ونظيف (UI/UX):**
  * تم التصميم باستخدام Pure CSS بدون استخدام Bootstrap لضمان خفة الأداء والتحكم الكامل.
